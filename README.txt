ClassSphere 0.1.7 - WoW 2.4.3 / TBC

INSTALLATION
1. Copier le dossier ClassSphere dans Interface/AddOns/
2. Vérifier : Interface/AddOns/ClassSphere/ClassSphere.toc
3. Lancer WoW.
4. /cs ou /classsphere pour ouvrir la configuration.
5. Clic droit sur le bouton central = configuration.
6. Déverrouiller le bouton central dans la configuration puis le faire glisser pour le déplacer.

0.1.7

- Suppression de toutes les textures BLP personnalisées/Totemus devenues inutiles.
